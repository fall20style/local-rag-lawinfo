KV Cache Quantization · Memory

KV 캐시 양자화 — 프리미스 메모리 47% 절감

n_ctx=8192 기준 공식 컨텍스트 생성 보고값 · q8_0 (flash_attn=True)

KV 버퍼 크기 (MiB)

해석

  • K만 절반: −105 MiB (−23%)
  • K+V 둘 다: −210 MiB (−47%)
  • 절감량은 컨텍스트 길이에 선형 비례 — n_ctx 2048에서는 −53 MiB로 작음
  • V 캐시 양자화는 Flash Attention 필수
  • compute buffer: 311 → 318 MiB (dequant 스크래치로 약 +7 MiB)
품질: KV 수치 변화가 greedy 출력에 미세 영향 → 응답 길이 55~106 tok 변동 관측. 법률 정답성 우선이면 품질 점검 권장
KV Cache Quantization · Speed

KV q8_0 속도 — 컨텍스트 짧으면 이득, 길면 손해

KV 양자화의 득실은 컨텍스트 길이가 갈렸다 (2회 반복 평균, q1 예열 제외)

n_ctx = 2048 — 실서비스 구간

RAM −47% + 속도 +16% — 동시 개선

n_ctx = 8192 — 긴 문서 주입 구간

디코드 어텐션이 전체 KV를 순회하며 q8 dequant 비용이 컨텍스트 길이에 비례 → CPU에서는 f16보다 느려지는 반전. 해법: type_v를 f16으로 (K만 양자화 −23%)
